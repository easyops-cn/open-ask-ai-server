基于 [Monaco Editor](https://github.com/microsoft/monaco-editor) 的代码编辑器。

```yaml preview
brick: vs.code-editor
properties:
  language: typescript
  value: |
    function sayHello(): string {
      return "hello";
    }

vs/code-editor
# -- YAML HEADING DELIMITER end (1nbbm8) --
# -- YAML DELIMITER (1nbbm8) --
# <vs.code-editor
#   language="typescript"
#   value='function sayHello(): string {
#   return "hello";
# }
# '
# ></vs.code-editor>
# 
```
