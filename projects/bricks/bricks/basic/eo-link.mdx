```html preview

```

## Examples

### Internal links

设置 `url` 用于单页应用内的链接跳转。

```html preview
<eo-link url="/some/internal/page">Internal page</eo-link>
<!-- HTML HEADING DELIMITER start (1nbbm8) --
basic/eo-link/internal links
-- HTML HEADING DELIMITER end (1nbbm8) -->
<!-- HTML DELIMITER start (1nbbm8) --
brick: eo-link
properties:
  url: /some/internal/page
  textContent: Internal page
-- HTML DELIMITER end (1nbbm8) -->
```

### External links

如果设置了 `href`，将使用原生 `<a>` 标签来实现链接跳转，通常用于外链的跳转。

```html preview
<eo-link href="https://baidu.com/" target="_blank" show-external-icon>
  Link to Baidu
</eo-link>
<!-- HTML HEADING DELIMITER start (1nbbm8) --
basic/eo-link/external links
-- HTML HEADING DELIMITER end (1nbbm8) -->
<!-- HTML DELIMITER start (1nbbm8) --
brick: eo-link
properties:
  href: 'https://baidu.com/'
  target: _blank
  showExternalIcon: true
  textContent: ' Link to Baidu '
-- HTML DELIMITER end (1nbbm8) -->
```

### As text

设置 `type="text"` 可以将链接以普通文本的样式进行渲染。

```html preview
<p>
  There is a
  <eo-link type="text" href="https://baidu.com/" target="_blank">
    link to Baidu
  </eo-link>
  that is hidden in the normal text.
</p>
<!-- HTML HEADING DELIMITER start (1nbbm8) --
basic/eo-link/as text
-- HTML HEADING DELIMITER end (1nbbm8) -->
<!-- HTML DELIMITER start (1nbbm8) --
brick: p
children:
  - brick: span
    properties:
      textContent: ' There is a '
  - brick: eo-link
    properties:
      type: text
      href: 'https://baidu.com/'
      target: _blank
      textContent: ' link to Baidu '
  - brick: span
    properties:
      textContent: ' that is hidden in the normal text. '
-- HTML DELIMITER end (1nbbm8) -->
```

### Plain

设置 `type="plain"` 链接不会拥有额外样式，适合搭配其他构件使用。

```html preview
<eo-link href="https://baidu.com/" target="_blank" type="plain">
  <eo-tag color="blue">Link to Baidu</eo-tag>
</eo-link>
<!-- HTML HEADING DELIMITER start (1nbbm8) --
basic/eo-link/plain
-- HTML HEADING DELIMITER end (1nbbm8) -->
<!-- HTML DELIMITER start (1nbbm8) --
brick: eo-link
properties:
  href: 'https://baidu.com/'
  target: _blank
  type: plain
children:
  - brick: eo-tag
    properties:
      color: blue
      textContent: Link to Baidu
-- HTML DELIMITER end (1nbbm8) -->
```
