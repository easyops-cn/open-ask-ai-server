数字格式化，支持普通数字、货币、百分比、二进制字节等数字的格式化显示。

## Examples

### Basic

```yaml preview
brick: eo-formatter-number
properties:
  value: 314159265
# -- YAML HEADING DELIMITER start (1nbbm8) --
basic/eo-formatter-number/basic
# -- YAML HEADING DELIMITER end (1nbbm8) --
# -- YAML DELIMITER (1nbbm8) --
# <eo-formatter-number value="314159265"></eo-formatter-number>
# 
```

### Currency

```yaml preview
brick: eo-formatter-number
```
