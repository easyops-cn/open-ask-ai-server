## Examples

### Basic

```yaml preview
- brick: eo-counter-badge
  properties:
    textContent: 我的通知
    count: 15
    overflowCount: 99
# -- YAML HEADING DELIMITER start (1nbbm8) --
basic/eo-counter-badge/basic
# -- YAML HEADING DELIMITER end (1nbbm8) --
# -- YAML DELIMITER (1nbbm8) --
# <eo-counter-badge count="15" overflow-count="99">我的通知</eo-counter-badge>
# 
```

### slot

```yaml preview
- brick: eo-counter-badge
  properties:
    showZero: true
    count: 100
  children:
    - brick: div
      properties:
        style:
          font-size: 16px
        textContent: 我的待办
# -- YAML HEADING DELIMITER start (1nbbm8) --
basic/eo-counter-badge/slot
# -- YAML HEADING DELIMITER end (1nbbm8) --
# -- YAML DELIMITER (1nbbm8) --
# <eo-counter-badge show-zero count="100">
#   <div style="font-size: 16px">我的待办</div>
# </eo-counter-badge>
# 
```

### icon

```yaml preview
- brick: eo-counter-badge

    dot: false

# 
```
