构件 `ai-portal.dropdown-select`

下拉选择器组件，提供选项列表供用户选择，支持搜索过滤功能。

## Examples

### Basic

基础用法，提供选项列表：

```yaml preview
brick: ai-portal.dropdown-select
properties:
  options:
    - label: "选项1"
      value: "option1"
    - label: "选项2"
      value: "option2"
    - label: "选项3"
      value: "option3"
  value: "option1"
events:
  change:
    action: "console.log"
# -- YAML HEADING DELIMITER start (1nbbm8) --
ai-portal/dropdown-select/basic
# -- YAML HEADING DELIMITER end (1nbbm8) --
```
