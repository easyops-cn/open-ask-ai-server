构件 `ai-portal.notice-dropdown`

消息通知下拉框构件，用于展示消息列表。支持自定义触发器、消息列表展示、空状态、以及交互事件。

### 自定义触发器（使用 eo-button）

  dataSource:
    - id: "msg-1"
      isRead: false
      type: "project"
      title: "协作流【研发设计】已完成"
    - id: "msg-2"
      isRead: false
      type: "space"
      title: "协作流【协作流名称】需要人工确认"
    - id: "msg-3"
      type: "account"
      isRead: true
      title: "【项目协作功能】已发布"
children:
  - brick: eo-button
    slot: trigger
    properties:
      type: primary
      icon:
        lib: "antd"
        icon: "bell"
      textContent: "查看通知"
