## Examples

### Fill Vertical

```yaml preview
brick: div
properties:
  style:
    height: 300px
children:
  - brick: eo-card
    properties:
      cardTitle: Hello
      fillVertical: true
      style:
        height: 100%
    children:
      - brick: div
        properties:
          textContent: World
          style:
            background: var(--palette-green-2)
            height: 100%
# -- YAML HEADING DELIMITER start (1nbbm8) --
containers/eo-card/fill vertical
# -- YAML HEADING DELIMITER end (1nbbm8) --
# -- YAML DELIMITER (1nbbm8) --
# <div style="height: 300px">
#   <eo-card card-title="Hello" fill-vertical style="height: 100%">
#     <div style="background: var(--palette-green-2); height: 100%">World</div>

#
```
